# VNet-L2

VNet-L2 is an educational Layer 2 virtual networking project written in Rust.

The project aims to demonstrate how Ethernet frames can travel between virtual network interfaces over a UDP-based transport.

## Learning Objectives

- Understand Ethernet frames
- Work with MAC addresses
- Implement MAC address learning
- Implement Layer 2 forwarding
- Work with UDP sockets
- Work with TAP interfaces
- Inspect network traffic
- Explore virtual networking and VPN architecture

## Technology

- UDP
- Linux
- TAP
- Git
